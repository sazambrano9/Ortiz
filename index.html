Mis cuentas

Sobre los saldos

El saldo es calculado a partir del saldo inicial y los movimientos vinculados a cada cuenta.

Las tarjetas de crédito se muestran como deuda pendiente. El registro de gastos con tarjeta aumenta la deuda.

Para traspasos entre cuentas y pagos de tarjeta, incorporaremos un módulo específico para evitar duplicar gastos.

Gastos e ingresos recurrentes

Las recurrencias son recordatorios. Pulsa «Registrar ahora» para confirmar cada movimiento; no se descuentan automáticamente.

Miembros de la familia

Uso compartido

En este prototipo puedes atribuir gastos a distintos miembros. Todos los datos permanecen en este navegador.

Para que cada familiar registre desde su propio teléfono y todos vean los mismos datos, será necesario implementar inicio de sesión y sincronización con un servidor.

Respaldo de información

Exporta los registros a un archivo JSON para guardarlos o trasladarlos a otro dispositivo. También puedes importarlos.

Datos de demostración

Carga gastos e ingresos ficticios para explorar el dashboard. Solo disponible cuando no existan movimientos.
